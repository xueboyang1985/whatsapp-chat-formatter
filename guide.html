Getting Started

  1. Open WhatsApp and export a chat (Without Media for free)
  2. Save the .txt file to your device
  3. Drag and drop the .txt file into the tool
  4. Preview messages with date/time and sender info
  5. Export as Markdown, HTML, TXT, CSV, or JSON

FAQ

How do I export a WhatsApp chat?

Open WhatsApp → open the chat → tap the contact/group name → Export Chat → choose Without Media (free) or With Media (PRO).

What is the free limit?

Free version exports the first 100 messages. PRO users can export unlimited messages and process ZIP exports with media files.

Are my chats uploaded to a server?

No. All processing happens in your browser. Your chat data never leaves your device.
